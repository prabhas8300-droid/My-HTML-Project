Executive Summary & Objective The Annapurna Canteen Automation Framework is designed to digitize and optimize food procurement workflows within the Vel Tech Campus Hub. It replaces traditional manual entry desks with a structured transactional runtime engine. The software eliminates queues by enabling real-time client-side calculation parameters, capturing secure identity markers, routing localized campus data pipelines, and outputting transactional receipts formatted directly for automated verification at the kitchen counter desk. 2. B. Core Function Specification 1. updateItemQuantity(itemName, quantity) • Logic: Checks if the input number configuration dropped below or equal to zero. If true, deletes the item key array out of the cart object to save application memory. If positive, sets the price mapping element against input volume counts. 2. calculateTotalPayableSum() • Logic: Iterates over item attributes using a for...in array block. Sums items total by evaluating (qty * price) parameters. Inject changes instantly into total-selected-elements and total-payable-sum document nodes. 3. verifyAndFinalizeOrder() • Logic: Extracts identification text files (student-roll-id, mobile-contact-terminal). Validates that strings are populated and that the cart contains elements. If successful, shifts metric states, updates dashboard nodes, and triggers receipt generator handlers. 5.
