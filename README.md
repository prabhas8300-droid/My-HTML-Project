# Annapurna Canteen - Vel Tech Backend Hub

An automated campus food-ordering framework designed for the Vel Tech Campus Main Food Court (Phase 1 Hub, Avadi, Chennai). This system manages user authentication, dynamic menu selections, a checkout transactional matrix, live queue tracking, and automated digital invoice rendering.

## 🚀 System Architecture

The automation framework consists of the following components:
* **Frontend Portal:** `index.html` houses the portal interface, menu categories, checkouts, and print nodes.
* **Styling Sheet:** `style.css` dictates structural matrix grids, campus color pallets, and adaptive layouts.
* **Execution Logic:** `script.js` handles client-side state mapping, payment gateways, and calculations.

## 📁 File Structure Configuration

Deploy the following layout inside your GitHub repository:
```text
├── index.html          # Portal Access, Menu Managers, Invoice Templates
├── style.css           # Styling matrix, campus colors, custom buttons
├── script.js           # Checkout loop, calculations, pipeline arrays
└── assets/             # QR codes, campus vault logos, system graphics
```

## 🛠️ Main Core Modules

1. **Portal Security Access Matrix:** Handles student ID and password key verifications.
2. **Dynamic Menu Matrix:** Categorizes delicacies across Tiffin, Meals, Snacks, Drinks, and Dinner.
3. **Transactional Checkout Engine:** Validates quantities, updates pipelines, and routes payment gateways.
4. **Automated Invoice Terminal:** Generates real-time receipts with custom transactional keys.
